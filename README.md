# Beauty by M — demo stranica

Demo Vue 3 + TypeScript (Vite) stranica za frizerski salon "Beauty by M" (Pula), s online rezervacijom termina (demo flow, bez backend integracije).

## Pokretanje

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Podaci o uslugama, cijenama i radnom vremenu nalaze se u [src/data/salon.ts](src/data/salon.ts).
